# Kommentare für weltraumnomaden.de

Dieses Repository speichert die Kommentare des Blogs [weltraumnomaden.de](https://weltraumnomaden.de).
Jeder Beitrag hat hier eine eigene Diskussion; angelegt und angezeigt werden sie über
[giscus](https://giscus.app/de) direkt auf der Website.

Zum Kommentieren bitte die Kommentarfunktion unter dem jeweiligen Beitrag nutzen.
Den Code der Website gibt es hier nicht.
